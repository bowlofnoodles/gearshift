# Complex Mode

Use Complex for everything that is not an obvious Quick change. Complex keeps alignment lightweight and Codex-native: focused questioning with `grill-me` and `grill-with-docs`, followed by Codex plan mode and implementation.

1. Use `grill-me` and `grill-with-docs` to clarify requirements, constraints, acceptance criteria, and relevant documentation. Let those Skills write or structure their notes however they normally do.
2. Enter Codex plan mode to produce the implementation plan. Let plan mode use its native behavior; Gearshift does not choose or enforce a document location.
3. Implement in the current workspace unless the user asks for isolation.
4. Run relevant verification before completing the work.

Do not use the removed Standard or Full gears. Do not invoke third-party workflow frameworks unless the user explicitly requests them.

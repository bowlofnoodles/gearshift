# Changelog

All notable changes to Gearshift will be documented in this file.

## 0.1.0 - 2026-07-11

### Added

- Complexity-aware Quick, Standard, and Full workflows.
- Natural-language routing and explicit Codex/Claude Code commands.
- Canonical `.gear/` artifacts with resumable Standard and Full tasks.
- Idempotent repository initialization and managed routing guidance.
- Read-only Doctor diagnostics and artifact validation.
- Codex Skills, Claude Code commands, and a compact SessionStart hook.
- Deterministic routing corpus and external-response scorer.
- English and Simplified Chinese documentation.
